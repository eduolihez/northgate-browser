# Security Policy

## Supported Versions

Only the latest release version is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| v0.1.x  | ✅ Yes    |
| < v0.1  | ❌ No     |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you discover a security vulnerability in NorthGate Browser (e.g., privilege escalation risks, classifier bypass methods, or memory safety concerns in the Rust component), please report it responsibly by contacting the project maintainer privately. 

To report a vulnerability:
1. Open a private vulnerability report via GitHub Security Advisories (if enabled on the repository).
2. Or contact the maintainer directly through the contact details listed on [eduolihez.com](https://eduolihez.com).

Please include:
* A detailed description of the vulnerability.
* Steps to reproduce or proof-of-concept (PoC) code/URLs.
* The operating system and version of NorthGate Browser tested.

We will acknowledge your report within 48 hours and work with you to coordinate a security patch before public disclosure.
